## Scope We Agreed

Under our binding written MoU, KDEV agreed to the following deliverable boundaries before writing code:

- **Creator Management:** Custom profile URLs, biographical links, and visual branding controls.
- **Supporter Tiers:** One-time tipping flow and recurring monthly membership subscriptions.
- **Supporter Stream:** Private supporter updates and activity feeds with rich media embeds.
- **Payout Ledger:** Transaction history export and webhook verification with payment gateways.

## Built With

Our team chose technologies that maximize founder runway, maintainability, and deployment portability:

- **Next.js App Router:** Server components deliver instant page loads for creator landing pages.
- **PostgreSQL:** Transaction-safe ledger design ensuring immutable balance tracking.
- **Docker & GitHub Actions:** Infrastructure reproducible on any cloud host with zero vendor lock-in.
