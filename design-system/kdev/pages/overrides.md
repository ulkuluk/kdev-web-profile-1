# KDEV: documented overrides of MASTER.md

`MASTER.md` is generated by ui-ux-pro-max and stays untouched. Where the project deliberately
deviates, the deviation is recorded here. These rules win over MASTER for KDEV.

| # | MASTER says | KDEV does | Why |
|---|-------------|-----------|-----|
| 1 | Accent/CTA `#EA580C`, on-accent `#000000` (button spec uses white) | Accent `#C2410C`, on-accent `#FFFFFF`, hover `#9A3412` | White on `#EA580C` is about 3.6:1 and fails AA. White on `#C2410C` is about 5.2:1. |
| 2 | Secondary `#3B82F6` | Used for decoration only (lines, glows, fills). Blue text uses `--color-primary` `#2563EB` | `#3B82F6` is under 4.5:1 as text on the light background. |
| 3 | Single font Plus Jakarta Sans | Plus Jakarta Sans plus JetBrains Mono (labels, step numbers, code snippets, wordmark) | The brief asks for developer details. Mono is confined to small accents. |
| 4 | Glassmorphism | Applied to the header, hero cards and case-study mock UI only. Sections use plain cards on a faint blueprint grid. | Keeps the page readable and trustworthy, and avoids a generic template look. |
| 5 | Card background `#F8FAFC` | Cards are `#FFFFFF` (`--color-card`), as in the palette table | The CSS snippet and the palette table in MASTER disagree. The palette table wins. |

Tokens live in `src/app/globals.css` (`@theme`).
